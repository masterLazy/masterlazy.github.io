Tarjan 求割点和割边

Tarjan 可以在 O(n)O(n)O(n) 的时间复杂度内求出一个无向图中的割点、割边。

求割点​

在 Tarjan 的过程中，需要对每个节点 uuu 维护以下变量：

黑色为树边，橙色为非树边；红字为 dfn\text{dfn}dfn

  • DFS 序 dfnu\text{dfn}_udfnu​。dfn\text{dfn}dfn 是前序更新的，一旦我们进入一个节点，就更新它的 dfn\text{dfn}dfn。
  • 从 uuu 出发、可以经过树边和非树边、不经过 uuu 的父节点能到达的、DFS 序最小的节点的 DFS 序 lowu\text{low}_ulowu​。例如上图中 low2=4\text{low}_2=4low2​=4（2→1→32\to1\to32→1→3，dfn3=4\text{dfn}_3=4dfn3​=4）。low\text{low}low 是后序更新的，我们从 uuu 的子节点退出后，利用其信息更新 lowu\text{low}_ulowu​。（注意要把 lowu\text{low}_ulowu​ 初始化为 dfnu\text{dfn}_udfnu​）具体来说，当我们 DFS 到一条边 (u,v)(u,v)(u,v) 时：

    • 如果 vvv 未访问过，说明它是子节点，于是递归搜索 vvv。回溯时，lowu←min⁡{lowu,lowv}\text{low}_u\gets\min\{\text{low}_u,\text{low}_v\}lowu​←min{lowu​,lowv​}。这是因为：子节点的 low\text{low}low 不会“回头”，这样连下去的节点不会经过 uuu 的父节点。于是子节点能连到的 low\text{low}low，uuu 当然也能连到。

    • 如果 vvv 访问过了，说明它不是子节点。lowu←min⁡{lowu,dfnv}\text{low}_u\gets\min\{\text{low}_u,\text{dfn}_v\}lowu​←min{lowu​,dfnv​}。

我们判断某个点是否是割点的根据是：对于某个顶点 uuu，如果存在一个儿子 vvv，使得 lowv≥dfnu\text{low}_v \ge \text{dfn}_ulowv​≥dfnu​，即不能回到祖先，那么 uuu 点为割点。

例如上图中点 555（dfn5=3\text{dfn}_5=3dfn5​=3），容易看出其子树中所有节点的 low\text{low}low 都 >3\gt3>3，所以可以判断它是割点。

但是这个判据不适用于搜索起点 sss 就是割点的情况。请看下面的图（从 333 开始搜索）：

我们发现，如果 sss 不是割点，那么能从 sss 的任意一个直接儿子出发，到达图中所有节点。所以，sss 只会“向下搜”一次。反之，如果 sss“向下搜”了 ≥2\ge2≥2 次，说明 sss 就是割点。

注意

“不适用”的意思是：uuu 为搜索起点时，即使满足判据也不是割点，需要另外的判据。

总结 & 编码​

对于节点 uuu，其是割点，当且仅当：

  • uuu 不是搜索起点，且存在 uuu 的一个儿子 vvv，使得 lowv≥dfnu\text{low}_v\ge\text{dfn}_ulowv​≥dfnu​。
  • uuu 是搜索起点，且 uuu 在搜索树上只有一个儿子。

编码如下，请重点关注更新 low 的两行：

// 标记割点并统计割点数量
void tarjan(int rt, int fa = 0) {
    node[rt].low = node[rt].dfn = node[fa].dfn + 1;
    int son = 0;
    for (int e = node[rt].head; e; e = edge[e].next) {
        int v = edge[e].to;
        if (!node[v].dfn) { // 没搜到过，是儿子
            son++;
            tarjan(v, rt);
            node[rt].low = min(node[rt].low, node[v].low);
            if (fa != 0 && !node[rt].isCut && node[v].low >= node[rt].dfn) {
                node[rt].isCut = true, cnt++;
            }
        } else {
            node[rt].low = min(node[rt].low, node[v].dfn);
        }
    }
    if (fa == 0 && !node[rt].isCut && son > 1) {
        node[rt].isCut = true, cnt++;
    }
}

求割边​

方法和求割点非常类似。边 (u,v)(u,v)(u,v) 是割边，当且仅当 lowv>dfnu\text{low}_v\gt\text{dfn}_ulowv​>dfnu​。（不需要考虑 uuu 是根节点的问题）注意这里不能取等。
