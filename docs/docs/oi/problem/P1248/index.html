P1248 加工生产调度

这是 Johnson（贪心）法则的一个典型应用（笔者觉得也算是例题）。

难度省选/NOI−
算法贪心、邻项交换排序、Jhonson 法则
日期2025-11-03

题意简述​

现在有 nnn 个产品，A,BA,BA,B 两个车间。这些产品要先在 AAA 车间依次完成加工，然后被送往 BBB 车间。每个车间只能同一时间只能加工一个产品。这意味着如果一个产品在 AAA 车间加工完后，BBB 车间加工的上一个产品还没完成，则必须等待上一个产品在 BBB 车间加工完成，然后当前产品才能送入 BBB 车间加工。

现在已知每个产品在 AAA 车间加工所需的时间 AiA_iAi​，以及在 BBB 车间加工所需的时间 BiB_iBi​，求出加工这些产品所需的最短总时间，并求出此时的加工顺序。

范围：1≤n≤103, 1≤Ai,Bi≤103.1\le n\le10^3,\space1\le A_i,B_i\le10^3.1≤n≤103, 1≤Ai​,Bi​≤103.

思路 #1​

考虑编号为 iii，jjj 的两个产品，它们先后被加工（即它们在加工顺序上紧邻）。

假设先加工 iii，那么加工这两个产品总用时

T1=Ai+max⁡{Aj,Bi}+Bj.T_1=A_i+\max\{A_j,B_i\}+B_j.T1​=Ai​+max{Aj​,Bi​}+Bj​.

假设先加工 jjj，那么总用时

T2=Aj+max⁡{Ai,Bj}+Bi.T_2=A_j+\max\{A_i,B_j\}+B_i.T2​=Aj​+max{Ai​,Bj​}+Bi​.

先加工 iii 总用时最短，当且仅当

T1<T2,Ai+max⁡{Aj,Bi}+Bj<Aj+max⁡{Ai,Bj}+Bi.\begin{aligned} T_1&<T_2,\\ A_i+\max\{A_j,B_i\}+B_j&<A_j+\max\{A_i,B_j\}+B_i. \end{aligned}T1​Ai​+max{Aj​,Bi​}+Bj​​<T2​,<Aj​+max{Ai​,Bj​}+Bi​.​

让我们引入一个技巧：

max⁡{A,B}+min⁡{A,B}=A+B.\max\{A,B\}+\min\{A,B\}=A+B.max{A,B}+min{A,B}=A+B.（显然）

所以 max⁡{A,B}=A+B−min⁡{A,B}.\max\{A,B\}=A+B-\min\{A,B\}.max{A,B}=A+B−min{A,B}.

那么我们调整上式，即得：

Ai+(Aj+Bi−min⁡{Aj,Bi})+Bj<Aj+(Ai+Bj−min⁡{Ai+Bj})+Ai,min⁡{Ai,Bj}<min⁡{Aj,Bi}.(*)\begin{aligned} A_i+(A_j+B_i-\min\{A_j,B_i\})+B_j&<A_j+(A_i+B_j-\min\{A_i+B_j\})+A_i,\\ \min\{A_i,B_j\}&<\min\{A_j,B_i\}.\tag{*} \end{aligned}Ai​+(Aj​+Bi​−min{Aj​,Bi​})+Bj​min{Ai​,Bj​}​<Aj​+(Ai​+Bj​−min{Ai​+Bj​})+Ai​,<min{Aj​,Bi​}.​(*)

所以我们可以依据 (*)(\text{*})(*) 式对所有产品排序，就能得到总加工时长最短的加工队列。

具体来说，我们用 sort() 排序即可。bool operator<(another) 返回 true 时 *this 排在 another 前面，所以我们这样重载小于号：

bool operator<(const Product& another) {
    return min(a, another.b) < min(another.a, b);
}

按这样的思路，我们可以在洛谷上获得 100pts100pts100pts（Unaccepted），无法通过一组 Hack 数据（WA）：

Hack 数据

输入

7
6 1 7 1 1 1 6
3 1 3 1 6 1 10

输出

26
2 4 5 6 7 3 1

思路 #2​

为什么会出错呢？

有一点要提醒：当我们构造 operator<() 使用的条件时，应当满足严格弱序。（笔者有一篇文章专门介绍了序理论）我们来仔细看看刚刚我们得到的 (*)(\text{*})(*) 式：

min⁡{Ai,Bj}<min⁡{Aj,Bi}.\min\{A_i,B_j\}<\min\{A_j,B_i\}.min{Ai​,Bj​}<min{Aj​,Bi​}.

这个式子不满足严格弱序所要求的不可比的传递性。什么意思？对于两个数，如果 A≮BA\not<BA<B 且 B≮AB\not<AB<A，则说明 A,BA,BA,B 不可比（在二元关系 <<< 中）。本例中，A,BA,BA,B 不可比 ⇔\Leftrightarrow⇔ min⁡{Ai,Bj}=min⁡{Aj,Bi}\min\{A_i,B_j\}=\min\{A_j,B_i\}min{Ai​,Bj​}=min{Aj​,Bi​}。那不可比的传递性是什么意思？其实就是如果 A,BA,BA,B 不可比，B,CB,CB,C 不可比，那么 A,CA,CA,C 也应该不可比。本例中，意思就是：

min⁡{Ai,Bj}=min⁡{Aj,Bi},min⁡{Bi,Cj}=min⁡{Bj,Ci}⇒min⁡{Ai,Cj}=min⁡{Aj,Ci}.\begin{aligned} \min\{A_i,B_j\}&=\min\{A_j,B_i\},\\ \min\{B_i,C_j\}&=\min\{B_j,C_i\}\\ \Rightarrow\min\{A_i,C_j\}&=\min\{A_j,C_i\}. \end{aligned}min{Ai​,Bj​}min{Bi​,Cj​}⇒min{Ai​,Cj​}​=min{Aj​,Bi​},=min{Bj​,Ci​}=min{Aj​,Ci​}.​

笔者觉得，到这里已经很明白了。譬如我们看式子左边，假如 Ai<BjA_i<B_jAi​<Bj​，Bi<CjB_i<C_jBi​<Cj​，我们并不能判断 Ai<CjA_i<C_jAi​<Cj​（注意下标）；再看右边，假如 Aj<BiA_j<B_iAj​<Bi​，Bj<CiB_j<C_iBj​<Ci​，并不能判断 Aj<CiA_j<C_iAj​<Ci​。更严谨地说，即使刚才这段话的所有条件同时成立，我们也不能推出第三行的结论。为了印证这一点，我们可以构造一个 Hack 数据：

min⁡{10,20}=min⁡{30,40},min⁡{40,20}=min⁡{20,114}⇒min⁡{10,20}=min⁡{30,114}?\begin{aligned} \min\{10,20\}&=\min\{30,40\},\\ \min\{40,20\}&=\min\{20,114\}\\ \Rightarrow\min\{10,20\}&=\min\{30,114\}? \end{aligned}min{10,20}min{40,20}⇒min{10,20}​=min{30,40},=min{20,114}=min{30,114}?​

那，我们怎么补救呢？我们只需特别处理一下 “不可比” 出现的情况，即 min⁡{Ai,Bj}=min⁡{Aj,Bi}\min\{A_i,B_j\}=\min\{A_j,B_i\}min{Ai​,Bj​}=min{Aj​,Bi​} 的情况就好了。
