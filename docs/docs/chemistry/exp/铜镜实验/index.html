铜镜实验

笔者有一个视频专门介绍此实验：【实验教程】低毒铜镜实验最佳实践！详细过程记录+全避坑+机理讲解。

备注

此实验成功率较低，对新手不太友好。

材料​

  • 硫酸铜
  • L-抗坏血酸（下称“抗坏血酸”）
  • 氨水（质量分数 ≥10%\ge10\%≥10%，建议用浓氨水）

非必需材料：

  • 氢氧化钠
  • 稀硫酸
  • 氯化亚锡

额外仪器：

  • 一个 10mL10\text{mL}10mL ~ 30mL30\text{mL}30mL 的气密小瓶子（下称“样品瓶”）

预处理​

  1. 依次用氢氧化钠溶液、稀硫酸洗涤样品瓶。
    具体流程：碱洗 →\rightarrow→ 水洗 →\rightarrow→ 酸洗 →\rightarrow→ 水洗

  2. 用适量硫酸酸化的蒸馏水配置 10g/L10\text{g/L}10g/L 的氯化亚锡溶液，将样品瓶浸泡 333 ~ 5min5\text{min}5min。然后用蒸馏水洗涤干净。

实验步骤​

注意

氨水有刺激性气味，本实验应在通风良好处进行。
建议戴手套、护目镜完成本实验。

  1. 取 2.5g2.5\text{g}2.5g（0.01mol0.01\text{mol}0.01mol）五水合硫酸铜，用 10mL10\text{mL}10mL 蒸馏水配成溶液。

  2. 取 1.76g1.76\text{g}1.76g（0.01mol0.01\text{mol}0.01mol）抗坏血酸，加入上述溶液。此时抗坏血酸与 Cu2+\text{Cu}^{2+}Cu2+ 配位，造成溶液颜色改变。
    颜色：蓝 →\rightarrow→ 绿

信息
  1. 不可以把五水合硫酸铜固体和抗坏血酸固体混合后一起配成溶液。
  2. 上述步骤得到的溶液不能久置，必须现用现配。
  3. 若溶解硫酸铜时加热了溶液，建议待溶液恢复常温后再进行下一步。
  1. 向溶液中加入过量氨水。此时会先生成棕色沉淀，然后沉淀逐渐溶解。注意：此步完成后，溶液应恢复澄清。
    颜色：绿 (aq)\text{(aq)}(aq) →\rightarrow→ 棕（浊液）→\rightarrow→ 棕绿（浊液）→\rightarrow→ 绛蓝 (aq)\text{(aq)}(aq) →…\rightarrow\dots→…
信息
  1. 此步会开始抗坏血酸还原 Cu2+\text{Cu}^{2+}Cu2+ 的进程，后续步骤需要加快。
  2. 必须使沉淀全部溶解，氨水必须足量。此步需要 NH3⋅H2O\text{NH}_3\cdot\text{H}_2\text{O}NH3​⋅H2​O 约 2.1g2.1\text{g}2.1g。
提示

若不能保证氨水足量，可考虑先倾出一部分溶液至样品瓶中，再滴加氨水至过量。如果沉淀完全溶解时加入的氨水太多（远大于 10mL10\text{mL}10mL），实验将失败。

  1. 将所得溶液注入准备好的样品瓶。尽量注满，旋紧。之后静置，等待铜镜逐渐生成（约 6h6\text{h}6h）。
    颜色：绛蓝 →\rightarrow→ 蓝绿 →\rightarrow→ 金黄 →\rightarrow→ 橙色（逐渐浑浊）
提示
  1. 向样品瓶内注入液体时应控制液体流速，避免破坏敏化层。使用滴管时要尤其小心，尽量垂直滴入，轻点挤。
  2. 金黄色是实验成功的好迹象。
  1. 倾出废液。为防止氧化，可以将抗坏血酸（约半药匙）的蒸馏水溶液注入成品，然后密封保存。

备注​

  1. Cl−\text{Cl}^-Cl− 会影响本实验，实验步骤（预处理除外）中应尽可能避免引入 Cl−\text{Cl}^-Cl−。
