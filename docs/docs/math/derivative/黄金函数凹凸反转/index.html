黄金函数×凹凸反转

所谓黄金函数，指的是一些有极值的“母函数”。记忆这些函数，可以为解题提供思路指引。如果发现题目里有这些函数就偷着乐吧。做题时，只需要把函数凑成黄金函数即可求得极值（化归/模型思想）。

而所谓凹凸反转法，指的是证明不等式时，构造两个凹凸性相反的函数，然后通过比较极值来间接证明不等式成立。有点类似一种放缩技巧。这样的好处是避免了整体研究的复杂，相当于把证明任务分成了两个子任务，每个都容易解决。

通常我们会构造两个凹凸性相反的黄金函数，因而黄金函数和凹凸反转是紧密关联的。

凹凸反转法​

凹凸反转法的核心即构造两个凹凸性相反的黄金函数，通过分别求两个黄金函数的极值，间接证明不等式成立。常用处理技巧有同乘/除 xxx，exln⁡xe^x\ln xexlnx等。

例 1​

证明：exln⁡x>1−2ex−1xe^x\ln x>1-\dfrac{2e^{x-1}}{x}exlnx>1−x2ex−1​ 恒成立。

即证

xln⁡x+2e>xexx\ln x+\dfrac2e>\dfrac x{e^x}xlnx+e2​>exx​

拆成两个黄金函数

xln⁡x+1e>xex−1ex\ln x+\dfrac1e>\dfrac x{e^x}-\dfrac1exlnx+e1​>exx​−e1​

根据上面的图像可得

xln⁡x≥−1e,  xex≤1ex\ln x\ge-\dfrac1e,\;\dfrac x{e^x}\le\dfrac1exlnx≥−e1​,exx​≤e1​

这两个不等式不能同时取等，因而得证 xln⁡x+2e>xexx\ln x+\dfrac2e>\dfrac x{e^x}xlnx+e2​>exx​。证毕。

例 2​

证明：ex−1ln⁡x+1>12(x+1x)\dfrac{e^{x-1}}{\ln x+1}>\dfrac12(x+\dfrac1x)lnx+1ex−1​>21​(x+x1​) 恒成立。

即证

ex−1>12(x+1x)(ln⁡x+1)e^{x-1}>\dfrac12(x+\dfrac1x)(\ln x+1)ex−1>21​(x+x1​)(lnx+1)

即证

xex−1>12(x2+1)(ln⁡x+1)xe^{x-1}>\dfrac12(x^2+1)(\ln x+1)xex−1>21​(x2+1)(lnx+1)

不等式两边大约是 xex>xln⁡xxe^x>x\ln xxex>xlnx 的形式，然而这两个函数同凹，不行。

整理得

ex−1x2+1>12(ln⁡x+1)x\dfrac{e^{x-1}}{x^2+1}>\dfrac12\dfrac{(\ln x+1)}xx2+1ex−1​>21​x(lnx+1)​

现在不等式两边大约是 ex>ln⁡xx\dfrac ex>\dfrac{\ln x}xxe​>xlnx​，凹凸性恰相反，分别求得极值即可，下略。证毕。

小结​

通过例 2 可以发现，如果把黄金函数中的 xxx 带换成其他多项式，得到的图像虽然大不相同，但是极值和凹凸性结论大致相同。黄金函数给我们提供了很好的判断极值和凹凸性的工具。

习题​

使用凹凸反转法证明：x+ln⁡x−2ex−1≤−1x+\ln x-2e^{x-1}\le-1x+lnx−2ex−1≤−1 恒成立。
