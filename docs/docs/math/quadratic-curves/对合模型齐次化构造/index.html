对合模型×齐次化构造

“对合（Involution）”在数学中的意思是“一个映射做两次就回到原处”，即 f[f(x)]=xf[f(x)]=xf[f(x)]=x。此时 fff 就叫对合映射。不过，高考圆锥曲线语境下的对合模型上面的定义没什么关系。

本文介绍的对合模型同样属于射影几何的内容，且与极点极线有密切的关系。不过我在写这篇笔记时，认为要捋清楚两者的联系太困难了，作为高中生，我们就把它当作一个黑盒来使用就好。

“斜率关系”​

如果两直线满足以下任意一个等式，则称这两条直线有“斜率关系”：

  • 斜率之和为定值：k1+k2=γk_1+k_2=\gammak1​+k2​=γ；
  • 斜率之积为定值：k1k2=γk_1k_2=\gammak1​k2​=γ；
  • 斜率倒数之和为定值：1k1+1k2=γ\dfrac{1}{k_1}+\dfrac{1}{k_2}=\gammak1​1​+k2​1​=γ；
  • 对合方程：αk1k2+β(k1+k2)+γ=0\alpha k_1k_2+\beta(k_1+k_2)+\gamma = 0αk1​k2​+β(k1​+k2​)+γ=0。

如果题目中出现了这些斜率关系，可以考虑对合模型或齐次化构造。

对合模型​

对于圆锥曲线上 A,M,NA,M,NA,M,N 三点，有如下定理（aka 手电筒模型）：

{AM,AN满足斜率关系,A为定点,⇒MN过定点.\begin{cases} AM,AN\text{满足斜率关系},\\ A\text{为定点}, \end{cases} \Rightarrow MN\text{过定点}.{AM,AN满足斜率关系,A为定点,​⇒MN过定点.

实际上，这三个条件知二推一。此外还有：

{AM,AN满足斜率关系,MN过定点,⇒A为定点.\begin{cases} AM,AN\text{满足斜率关系},\\ MN\text{过定点}, \end{cases} \Rightarrow A\text{为定点}.{AM,AN满足斜率关系,MN过定点,​⇒A为定点. {A为定点,MN过定点,⇒AM,AN满足斜率关系.\begin{cases} A\text{为定点},\\ MN\text{过定点}, \end{cases} \Rightarrow AM,AN\text{满足斜率关系}.{A为定点,MN过定点,​⇒AM,AN满足斜率关系.

根据这些定理，我们可以快速地判断很多定点/定直线问题。

一般思路：先猜后证​

如果判定了某题属于对合模型，则可以遵循以下思路解题：

  • 找特殊情况，蒙出答案。
  • 列出韦达定理，翻译题目条件，假意证明几步。不出意外的话，最后会得到一坨恶心的式子。在这一步停下来，不要硬刚。
  • 根据答案构造出因式分解之式，直接写在“整理得”后面。
  • 完成证明，表演成功。

齐次化构造​

当题目中出现了如 k1+k2,k1+k2,1k1+1k2k_1+k_2,k_1+k_2,\dfrac{1}{k_1}+\dfrac{1}{k_2}k1​+k2​,k1​+k2​,k1​1​+k2​1​ 这类式子时，往往可以使用齐次化构造，直接求出斜率关系而不用求交点坐标，减小计算量。

下面用 例 1 来演示齐次化构造的技巧。

解

当直线 MNMNMN 斜率存在时，因为 MNMNMN 不过 AAA，设 MN:m(x−2)+n(y−2)=1MN: m(x-2)+n(y-2)=1MN:m(x−2)+n(y−2)=1。

总结一下要点步骤：

  1. 因为两条直线都过 AAA，所以第一步列方程的时候关于 AAA 的坐标来列；
  2. 接下来对曲线方程变形，整理；
  3. 利用第一步得到的方程，对整理后的曲线方程进行齐次化构造；
  4. 合并同类项，两边同除，就能得到关于斜率的方程；
  5. 利用韦达定理表述题目约束条件，即得 m,nm,nm,n 间关系；
  6. 利用对比法求出定点。

相比前面先猜后证的方法，齐次化构造不需要蒙答案，也不需要表演，我觉得比较自然。在使用齐次化构造之前，要注意判断题设的条件能不能用关于斜率的韦达表示，不然计算量一样很大。
