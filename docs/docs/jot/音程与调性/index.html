音程与调性

这是乐理的两个核心概念。稍后介绍的调式理论、和弦理论等都以此为基础。

音程​

音程衡量两个音之间的频率差异。比如 f1,f2f_1,f_2f1​,f2​ 两个频率的声音，若 f1:f2=2:1f_1:f_2=2:1f1​:f2​=2:1，则称 f1f_1f1​ 在 f2f_2f2​ 上方纯八度；若 f1:f2=3:2f1:f2=3:2f1:f2=3:2，则称 f1f_1f1​ 在 f2f_2f2​ 上方纯五度。八度和五度是音乐中最重要的两个音程：相隔八度的音有“相同”的感觉；相隔五度的音听起来很和谐。

频率之比小于 16:1516:1516:15 的音，他们之间的音程称为半音（大概如此）。

大音程的听感往往比小音程更和谐。小音程、增减音程的听感往往比较紧张。你可能会发现有的音程有不同的称呼——这需要依上下文而定。音程的名字含有对其功能或听感的暗示，而不仅仅是一个“名字”。在稍后的乐理介绍中，你可能会加深这个印象。

假设有两个音的组合 (a,b)(a,b)(a,b)，假设频率 a<ba<ba<b，现在把 bbb 降低八度得到新的组合 (b′,a)(b',a)(b′,a)，这样的操作叫做转位。当然，在上例中，把 aaa 升高八度也算转位。除了上文提到的纯五度和纯八度，纯四度也是一个重要的音程，它是纯五度的转位。

调性​

一首音乐中的音，其频率都有一定规律。在古今中外绝大多数音乐中，都可以找到一个集合 SSS，使得音乐中的任意一个频率为 fff 的音符，都有 2nf∈S(n∈Z)2^nf\in S (n\in \mathbb{Z})2nf∈S(n∈Z) 成立。记满足此条件的最小的集合为 S0S_0S0​，则我们把 S0S_0S0​ 中的音取出，按频率高低排序，就得到了这首歌的调性（如 C 大调）。这些音符之间往往有一定的组织规律，这种规律称为调律（如十二平均律）。

现代最流行的调律为十二平均律，其半音频率之比为 212:1\sqrt[12]{2}:1122​:1，即把八度十二等分，由此得名。古典作品中还有五度相生律（毕达哥拉斯律）、中庸平均律、纯律等，此处不介绍。
