# 色环电阻

| 类型     | 图示                                                         |
| -------- | ------------------------------------------------------------ |
| 4 环电阻 | <ColorDot/><ColorDot/><ColorDot color='tomato'/>&nbsp;&nbsp;&nbsp;&nbsp;<ColorDot color='blueviolet'/> |
| 5 环电阻 | <ColorDot/><ColorDot/><ColorDot/><ColorDot color='tomato'/>&nbsp;&nbsp;&nbsp;&nbsp;<ColorDot color='blueviolet'/> |
| 6环电阻  | <ColorDot/><ColorDot/><ColorDot/><ColorDot color='tomato'/>&nbsp;&nbsp;&nbsp;&nbsp;<ColorDot color='blueviolet'/><ColorDot color='gold'/> |

其中：

- <ColorDot/> 是数值色环，从左至右依次编号
- <ColorDot color='tomato'/>是倍率色环
- <ColorDot color='blueviolet'/>是误差色环
- <ColorDot color='gold'/>是温度系数色环

| 色环                                | 作为数值 | 作为倍率                 | 作为误差    | 作为温度系数    |
| ----------------------------------- | -------- | ------------------------ | ----------- | --------------- |
| <ColorDot color='black'/> 黑色      | $0$      | $10^0=1\Omega$           |             |                 |
| <ColorDot color='sienna'/> 棕色     | $1$      | $10^1=10\Omega$          | $\pm1\%$    | $100\text{ppm}$ |
| <ColorDot color='crimson'/> 红色    | $2$      | $10^2=100\Omega$         | $\pm2\%$    | $50\text{ppm}$  |
| <ColorDot color='tomato'/> 橙色     | $3$      | $10^3=1\text{k}\Omega$   |             | $15\text{ppm}$  |
| <ColorDot color='goldenrod'/> 黄色  | $4$      | $10^4=10\text{k}\Omega$  |             | $25\text{ppm}$  |
| <ColorDot color='green'/> 绿色      | $5$      | $10^5=100\text{k}\Omega$ | $\pm0.5\%$  |                 |
| <ColorDot color='royalblue'/> 蓝色  | $6$      | $10^6=1\text{M}\Omega$   | $\pm0.25\%$ |                 |
| <ColorDot color='blueviolet'/> 紫色 | $7$      | $10^7=10\text{M}\Omega$  | $\pm0.1\%$  |                 |
