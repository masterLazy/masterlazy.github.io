# 制图工具

一些非常好用的制图工具，mNotebook 中的一些图片也是用这些工具制作的。

## GeoGebra

- [GeoGebra 官网首页](https://www.geogebra.org/)
- [GeoGebra 计算器套件（在线使用）](https://www.geogebra.org/calculator)

其图形计算器功能强大，可以轻松绘制各种几何图形，画一些简单的示意图也不错。

## Graph Editor

- [Graph Editor - CS Academy](https://csacademy.com/app/graph_editor/)

图论画图的利器。支持有向图，无向图，可以直接拖拽。很好玩，很强大。

## Excel

- [Excel 网页版](https://excel.cloud.microsoft/)

笔者主要用 Excel 绘制散点图、折线图等。其功能强大（支持多组数据），网上也能用。
