# 可愛いロゴ

可愛いロゴ（Kawaii Logos）是 [@sawaratsuki1004](https://x.com/sawaratsuki1004)（さわらつき）创作的一系列可爱的（大多数是计算机科学相关的）logo。其似乎主要在 X 上发布作品，但是 TA 也创建了一个仓库 [KawaiiLogos](https://github.com/SAWARATSUKI/KawaiiLogos) 来记录这些作品。

:::note
不知什么原因，KawaiiLogos 仓库中的 logo 并不完整。笔者找到了以下仓库，记录更完整：
- https://github.com/CMander02/CuteServiceLogos
:::
