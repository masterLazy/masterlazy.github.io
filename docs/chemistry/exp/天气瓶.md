# 天气瓶

也有人叫“风暴瓶”。总之这是一个可以根据温度改变结晶状态的小瓶子，用来观赏很不错。

## 材料

- 天然樟脑
- 氯化铵
- 无水乙醇

非必需材料：

- 硝酸钾

## 实验步骤

1. 取 $1\text{g}$ 氯化铵、$1\text{g}$ 硝酸钾，用 $13\text{mL}$ 蒸馏水配成溶液。
2. 取 $4\text{g}$ 天然樟脑，用 $16\text{mL}$ 无水乙醇配成溶液。
3. 将以上两种溶液混合，然后水浴加热，直至所有樟脑溶解。

:::warning
天然樟脑和无水乙醇可燃，加热时需要格外小心。不能直接用酒精灯加热。\
成品也不能用明火加热。
:::

## 现象

成品会随温度变化而改变接近状态：

- 雪花状（降温快）
- 羽毛状（降温慢）
- 棉絮状（形成羽毛状后升温）

## 备注

- 不添加硝酸钾也可以实现相近的效果。
- 小心调整蒸馏水或无水乙醇的量，可以改变成品中析出晶体的温度（建议在 1~2 滴管以内）。
- 可以添加一些色素（如少量亚甲基蓝）以提升观赏效果。
